它完全免费，目前仍然免费，大家可以完全免费使用。无需注册，装好扩展就能用。

这是一款本地优先的多平台写作工具：你在 MaynorAI 编辑器里一次写好标题和正文，勾选目标平台，就能把同一篇文章写入多个平台的草稿箱，不用再来回复制粘贴。当前可同步到 20 个平台的草稿箱，还在持续扩展，已经覆盖微信公众号、知乎、掘金、CSDN、微博、百家号、博客园、头条、51CTO、简书、思否、开源中国、哔哩哔哩专栏、网易号、腾讯云开发者社区、抖音长文等。

几件我想先说清楚的事：

1. 默认只创建或更新草稿，不会直接发布。请到各平台后台检查标题、排版和图片，确认无误后再手动发布。
2. 登录凭据留在你的浏览器里。扩展只复用你已在网页端登录的会话，不必向 MaynorAI 提交平台 Cookie 或账号密码。
3. 对公众号做了排版适配：会把 Markdown 转成更适合公众号的富文本，代码块和图片按规则处理；建议仍在公众号草稿里预览后再发布。
4. 登录编辑器后，文章可以存到云端文章夹；没登录时，草稿也可以先留在本机，随时继续写。
5. 每次同步都会记入历史任务，可以查看各平台状态，失败了能直接重试。

三步开始用，支持 Chrome、Edge 等 Chromium 内核浏览器：

1. 按下面三种方式之一获取插件并解压。在 Chrome 打开 `chrome://extensions`（Edge 则是 `edge://extensions`），开启「开发人员模式」，选择「加载已解压的扩展程序」。
2. 在浏览器里正常登录微信公众号、知乎、CSDN、哔哩哔哩专栏等平台网页端。扩展会读取当前登录状态，不用再输入账号密码。
3. 打开编辑器写好文章，点击「同步到草稿箱」，勾选目标平台并创建任务。文章会以草稿形式写入各平台，你检查排版后再手动发布。
